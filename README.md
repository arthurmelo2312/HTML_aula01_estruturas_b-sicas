# HTML_aula01_estruturas_basicas
# Portfólio - Arthur Melo

Este projeto é um portfólio pessoal desenvolvido para apresentar um pouco sobre mim, minhas habilidades e alguns dos projetos que estou desenvolvendo na área de tecnologia.

## Sobre o Projeto

O site possui uma estrutura simples e organizada, contendo informações pessoais, habilidades, projetos e uma área para contato.

## Tecnologias Utilizadas

* HTML5
* JavaScript
* Python
* PHP
* MySQL

### Sobre Mim

Apresenta uma breve descrição sobre mim e minhas áreas de interesse.

### Habilidades

Lista algumas das tecnologias e linguagens que estou estudando e utilizando.

### Projetos

Exibe alguns projetos desenvolvidos, suas tecnologias e o status de desenvolvimento.

### Contato

Possui um formulário para envio de mensagens, com campos para nome, e-mail, assunto e mensagem.

## Objetivo

O objetivo deste projeto é praticar desenvolvimento web, organização de código HTML e criação de uma página de apresentação profissional.
